═════════════════════════════════════════════

📁 PROJECT STRUCTURE:
─────────────────────
SalesforceAutomation/
├── src/main/java/config/           ← Configuration classes
├── src/main/resources/              ← Property files per env
├── src/test/java/tests/             ← Test classes
├── .env.example                     ← Credentials template
└── CONFIG*, ARCHITECTURE, DELIVERY* ← Documentation


🚀 QUICK START:
───────────────

1. Create .env:
   cp .env.example .env

2. Edit .env:
   ADMIN_USERNAME=your_admin@salesforce.com
   ADMIN_PASSWORD=your_password
   USER_USERNAME=your_user@salesforce.com
   USER_PASSWORD=your_password

3. Run tests:
   mvn test


📋 KEY CLASSES:
────────────────

ConfigManager
  └─ Singleton, loads from properties + .env
  └─ Methods: getInstance(), getInstance(Environment), reset()

TestConfig (Interface)
  ├─ getBaseUrl()
  ├─ getApiUrl()
  ├─ getAdminCredentials()
  ├─ getStandardUserCredentials()
  ├─ getTimeouts()
  ├─ getBrowserSettings()
  ├─ getRetryConfig()
  └─ getEnvironment()

Environment (Enum)
  ├─ DEV
  ├─ STAGING
  └─ PRODUCTION

Credentials (Immutable)
  ├─ getUsername()
  └─ getPassword()

Timeouts (Immutable)
  ├─ getDefaultTimeout()
  ├─ getNavigationTimeout()
  └─ getAssertionTimeout()

BrowserSettings (Immutable)
  ├─ isHeadlessMode()
  ├─ getViewportWidth()
  ├─ getViewportHeight()
  └─ getBrowserType()

RetryConfig (Immutable)
  ├─ getMaxRetries()
  ├─ isScreenshotOnFailure()
  └─ isVideoRecordingOnFirstRetry()

🔧 USAGE EXAMPLES:
──────────────────

# Get credentials in tests:
Credentials admin = config.getAdminCredentials();
String username = admin.getUsername();
String password = admin.getPassword();

# Get browser settings:
BrowserSettings browser = config.getBrowserSettings();
boolean headless = browser.isHeadlessMode();

# Get timeouts:
Timeouts timeouts = config.getTimeouts();
long timeout = timeouts.getDefaultTimeout();

# Get retry config:
RetryConfig retry = config.getRetryConfig();
int maxRetries = retry.getMaxRetries();


🎯 RUN COMMANDS:
─────────────────

# Compile only
mvn clean compile

# Run tests (dev environment)
mvn test

# Run specific environment
mvn test -Denv=staging
mvn test -Denv=production

# With environment variables
export ENV=staging && mvn test

# Run specific test class
mvn test -Dtest=LoginTestValid

# Run with debugging
mvn test -X

🔐 CREDENTIALS SETUP:
─────────────────────

Option 1: .env file
─────────────────────
Create .env in project root:
  ADMIN_USERNAME=admin@salesforce.com
  ADMIN_PASSWORD=your_admin_password
  USER_USERNAME=user@salesforce.com
  USER_PASSWORD=your_user_password
  ENV=dev

Option 2: Environment variables
─────────────────────────────────
export ADMIN_USERNAME=admin@salesforce.com
export ADMIN_PASSWORD=your_password
export USER_USERNAME=user@salesforce.com
export USER_PASSWORD=your_password
mvn test

Option 3: Properties file (NOT recommended)
──────────────────────────────────────────────
Edit config-dev.properties:
  admin.username=admin@salesforce.com
  admin.password=password
  user.username=user@salesforce.com
  user.password=password


✅ VALIDATION RULES:
─────────────────────

✓ Properties file must exist for environment
✓ Credentials must not be null or empty
✓ Timeouts must be > 0
✓ Viewport dimensions must be > 0
✓ Max retries must be >= 0
✓ Browser type must be recognized (chrome/firefox)


🐛 TROUBLESHOOTING:
────────────────────

"Configuration file not found"
  → Check ENV variable or -Denv parameter
  → Ensure config-{env}.properties exists

"Credentials not configured"
  → Create .env file with ADMIN_USERNAME etc
  → Or set environment variables
  → Or update properties file

"Invalid timeout value"
  → Timeouts must be positive integers > 0
  → Check timeout.* properties

"Driver initialization failed"
  → Check browser settings configuration
  → Ensure browser type is chrome or firefox

✓ Use immutable config objects

🔄 ADDING NEW SETTINGS:
────────────────────────

1. Add to properties:
   my.setting=value

2. Add getter to ConfigManager:
   public String getMySettings() {
       return getStringProperty("my.setting", "default");
   }

3. Use in tests:
   String value = config.getMySettings();


⚡ PERFORMANCE TIP:
────────────────────

ConfigManager is Singleton:
  - Config loaded once per test run
  - Reused across all tests
  - No repeated file I/O
  - Thread-safe
