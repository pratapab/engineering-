EXTENDING THE CONFIGURATION:
═════════════════════════════

To add new settings:

1. Add property to config-*.properties:
   new.property=value

2. Add getter to ConfigManager:
   public String getNewProperty() {
       return getStringProperty("new.property", "default");
   }

3. Use in tests:
   String value = config.getNewProperty();
